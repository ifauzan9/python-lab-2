Bantuan Materi: Variabel + print()

1. Apa itu variabel?

Variabel adalah tempat untuk menyimpan data di dalam program.

nama = "Python" print(nama)

2. Apa fungsi print()?

print() digunakan untuk menampilkan sesuatu ke layar.

print("Halo") print("Saya belajar Python")

3. Teks dan angka

Teks memakai tanda kutip. Angka tidak perlu tanda kutip.

bahasa = "Python" pertemuan = 2 print(bahasa) print(pertemuan)

4. Variabel bisa diubah

status = "Belum Selesai" print(status) status = "Selesai" print(status)

5. Langkah mengerjakan tantangan

  1. Baca instruksi tantangan.
  2. Perhatikan target output.
  3. Ketik kodenya sendiri di editor.
  4. Tekan Run Python.
  5. Jika output benar, tantangan berikutnya terbuka.

6. Kesalahan umum

  • Menulis Print() padahal harus print().
  • Lupa tanda kutip pada teks.
  • Menampilkan variabel yang belum dibuat.
  • Salah menulis nama variabel.
